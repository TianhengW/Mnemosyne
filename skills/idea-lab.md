# Idea Lab — Research Idea Incubator

Help structure, develop, and critically evaluate research ideas. Designed for the ideation phase of PhD research.

## Instructions

### When the user has a new idea:
1. Help structure it using the framework below
2. Search the library (`semantic_search`, `search_papers`) to check for existing work
3. Search arXiv (`search_arxiv`) for very recent related work
4. Provide honest assessment of novelty and feasibility
5. Save to Obsidian at `Research/Ideas/[short-name].md`

### When the user wants to review existing ideas:
1. List ideas from `Research/Ideas/` folder
2. Help prioritize based on novelty, feasibility, and alignment with research direction

## Idea Structure Template

```markdown
# [Idea Title]

## One-sentence Summary
[What + How + Why it matters]

## Problem Statement
- What problem does this solve?
- Why is it unsolved / poorly solved now?
- Who cares about this problem?

## Proposed Approach
- Core insight/hypothesis
- High-level method
- Key technical components

## Expected Contribution
- [ ] Novel problem formulation
- [ ] Novel method/algorithm
- [ ] Novel application
- [ ] Significant empirical improvement
- [ ] Theoretical insight

## Feasibility Check
- **Data:** What data is needed? Available?
- **Compute:** What resources are needed?
- **Timeline:** Rough estimate (weeks/months)
- **Skills gap:** What do I need to learn?

## Related Work
- [Closest existing work and why this is different]
- [Papers from user's library that relate]

## Risks & Open Questions
- What could go wrong?
- What assumptions might be wrong?
- What's the minimum viable experiment?

## Status: [💡 New | 🔬 Exploring | 🚧 In Progress | ✅ Published | ❌ Abandoned]
## Priority: [High | Medium | Low]
## Last Updated: [date]
```

## Evaluation Criteria
When assessing ideas, consider:
1. **Novelty** (1-5): How new is this vs existing work?
2. **Feasibility** (1-5): Can a PhD-1 student do this in 3-6 months?
3. **Impact** (1-5): Would this be a solid paper at a top venue?
4. **Alignment** (1-5): Does this fit the user's research direction (world model + concept reasoning)?
5. **Learning value** (1-5): How much will the user grow from this?
