# Research Pulse — 研究健康度

聚合你的研究活动数据，生成趋势报告并检测异常。

## 使用场景

```
/research-pulse
```

Claude 会调用 `research_pulse()` 生成过去 4 周的研究活动报告，包括：
- 📄 论文阅读量（Zotero 新增）
- 📝 批注数量
- 💻 代码提交量
- 📒 笔记产出
- 🧪 实验进展

## Instructions

1. 调用 `research_pulse(weeks=4)` 获取完整报告
2. 如果发现异常（连续 2 周某项为 0），主动提醒用户
3. 与用户讨论：
   - 是否需要调整计划？
   - 卡在什么地方了？
   - 是不是该换个方向试试？

## 解读指南

| 信号 | 正常范围 | 预警条件 |
|------|----------|----------|
| 论文/周 | 2-5 篇 | 连续 2 周 = 0 |
| 批注/周 | 5-20 条 | 连续 2 周 = 0 |
| Commits/周 | 5-30 | 连续 2 周 = 0 |
| 实验/月 | 2-5 个 | 全部 failed 无 completed |

## 自动推送

每周日 20:00 通过 Server酱 推送周报（`daily-push.py --type pulse`）。

## 与其他功能的关联

- 如果阅读量下降 → 建议调整 `/reading-queue`
- 如果代码量激增但论文量为 0 → 提醒不要只写代码忘了读论文
- 如果实验全部 failed → 建议用 `/idea-lab` 重新评估方向
